# PNLCS documentation

PNLCS is a free, MIT-licensed, self-hosted hosting billing platform and client
portal, an open-source alternative to WHMCS. These pages explain how to
install it, run a hosting business with it, and build on it.

## What do you want to do?

- [Install PNLCS](install/index.md): with Docker, on your own server, or in a hosting panel account.
- [Make your first sale](getting-started/first-login.md): first login, the setup checklist, then a paid and provisioned order.
- [Move from WHMCS](guides/migrate-from-whmcs.md): what carries over, what does not, and the order to switch in.
- [Connect a server](guides/connect-a-server.md): create hosting accounts automatically when an order is paid.
- [Sell VPS on Proxmox VE](guides/sell-vps-on-proxmox.md): five steps from a Proxmox node to a customer's running VPS.
- [Sell Docker apps](guides/sell-docker-apps.md): WordPress, n8n and other apps inside the customer's plan limits.
- [Write a module or hook](developer/index.md): server, gateway and registrar modules; WHMCS-style hooks.
- [Fix a problem](troubleshooting/common-issues.md): common errors and their causes, and the FAQ.

## Build on PNLCS

- [API reference](api/index.md): 171 actions, plus an OpenAPI 3.1 file.
- [MCP server](mcp/index.md): 15 read tools, and 7 write tools if you allow them.
- [Hooks](developer/hooks.md) and [modules](developer/modules.md).
